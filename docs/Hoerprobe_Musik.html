Hörprobe: Beamer-Musik (Industrie-Version)

Alles wird live im Browser erzeugt (WebAudio): keine Musikdateien, keine Lizenzen, läuft offline. Aufbau wie Quiz-Show-Musik, Klang aus der Fabrikhalle: Pressenschläge, Pneumatik-Zischen, Relais-Klicks, Stahl statt Marimba, Warnleuchte, Servo, Fabrikpfeife. Eigene Kompositionen, keine Kopie der Kahoot-Melodien.

Bereit – klicke auf einen Knopf.

▶ Ganze Challenge durchspielen ca. 50 s

So würde es am Beamer klingen: Lobby → 3-2-1-Los → Challenge → letzte Minute (schneller) → Zeit abgelaufen → Siegerehrung. Die Zeit ist hier stark gerafft.

--:--

Lobby 118 BPM · F-Dur

Warten auf Teilnehmende. Hüpfender Groove: Presse, Pneumatik auf den Nachschlägen, Metall-Klang statt Klatscher, Melodie auf angeschlagenem Stahl. Neue Teilnehmende: „Pssht-Klack-Ping“.

Challenge 126 BPM · a-Moll

Treibend, die Uhr tickt als Schütz/Relais. „Letzte Minute“: Tempo auf 152 BPM, Warnleuchten-Signal, Servo fährt hoch, Presse im Viertel.

Siegerehrung 132 BPM · C-Dur

Fabrikpfeife, Trommelwirbel, Fanfare mit Amboss-Schlägen, Dampf ablassen, dann eine Jubelschleife fürs Podest.

Effekte

Kurze Klänge für Ereignisse am Beamer. „Zeit abgelaufen“ = Summer + Maschine fährt herunter.

Im Spiel würde die Musik nur am Beamer laufen (bei den Lernenden aus). Browser spielen Ton erst nach einem Klick – am Beamer passiert das mit „Challenge starten“.
